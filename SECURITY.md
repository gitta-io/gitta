# Security

## Report a problem

Send security problems to support@gitta.io with "security" in the subject. Do not open a public issue for them.

Tell us what you found, the gitta version and how to reproduce it. We confirm that we got your report within three working days, and we tell you what we will do and when. When the fix is released, we credit you in the release notes if you want us to.

## Versions that get fixes

We fix security problems in the newest release. Update with `gitta update` or `brew upgrade gitta`.

## Check a download

Every release file has a SHA-256 checksum next to it, and the install script and `gitta update` check it before they install anything. Each release also has software bills of materials (CycloneDX and SPDX) and a cryptography bill of materials.
