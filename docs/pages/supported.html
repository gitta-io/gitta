Supported platforms

The full list of what gitta works with today, and what comes next.

AI coding agents

AgentHow it works with gitta
Claude CodeSupported. Warnings arrive automatically through hooks. See Agents.
Cursor, CodexSupported through MCP tools, which the agent calls when your AGENTS.md tells it to.
Any tool that uses Git worktreesSupported, for example Conductor or Claude Squad. Warnings show in gitta status and gitta watch.
Cloud agents that open pull requestsSupported through the pull request check, for example GitHub Copilot’s coding agent, Codex cloud, Jules and Devin.

Git hosts and CI

SystemStatus
GitHub and GitHub ActionsSupported. See Pull requests and CI.
Jenkins, Buildkite, CircleCI and other CISupported through gitta pr-check --json. See CI/CD integration for teams.
IBM Dependency Based BuildWith gitta Enterprise, a step before the build. See Mainframe guide.

Operating systems for the gitta command

SystemStatus
macOS, Apple silicon and IntelSupported, with release builds
Linux, x86_64 and arm64Supported, with release builds. Shared copy-on-write workspaces and the agent sandbox are Linux only.
Windows, x86_64 and arm64Supported, with release builds

For mainframe teams, gitta runs on the developer machines and CI servers that hold the Git repositories.

Languages

LanguageWhat gitta does
Python, TypeScript, JavaScript, Go, Rust, Java, C#, KotlinMeaning analysis between agents, structural merge and security checks
C and C++, including headersMeaning analysis between agents, also through headers, and security checks. Structural merge for files that parse cleanly, the others line by line. See C and C++.
All other filesLine by line merge, and your tests on the combined work

Mainframe languages come with gitta Enterprise, see below.
