Uninstall

Removing gitta leaves a plain Git repository. Your branches, commits and worktrees stay.

From one repository

$ gitta uninstall gitta: removed 0 gitta workspace(s); adopted worktrees untouched gitta: removed from ~/src/microblog; it is a plain Git repository again gitta: agent hooks and MCP entries stay installed for your other repositories (remove them with `gitta uninstall --everywhere`)

This removes .gitta/, the git hooks and the merge driver setting that gitta added and any workspaces that gitta made itself. Worktrees that you or your agents made stay, with their work. On Linux, shared-checkout worktrees become ordinary worktrees again, with their changes.

Git notes under refs/notes/gitta stay. Delete them with git update-ref -d refs/notes/gitta if you want.

From your machine

$ gitta uninstall --everywhere

This also removes the Claude Code hooks and the Cursor and Codex MCP entries that gitta added. Your other settings stay. The last line of the output gives the command that deletes the program, for example:

$ rm ~/.local/bin/gitta

If you installed with Homebrew, run brew uninstall gitta instead.

gitta Enterprise

Run helm uninstall gitta, or delete the VMs, images and buckets that deploy.sh made. The servers' data folders hold the team's audit copies. Export them first if you must keep them, with gitta audit --team --json.

If something did not work as you expected, read Troubleshooting or write to Support.
