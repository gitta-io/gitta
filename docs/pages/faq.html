Frequently asked questions

Short answers to what teams ask before they start with gitta, each with a link to the page that has the details.

Is gitta free?

Yes. The gitta command is free and open source, and it runs on every machine with all its checks. gitta Enterprise is a paid yearly licence for teams. It adds the team server that connects agents on every machine, single sign-on and the shared audit trail. See gitta Enterprise.

Do I still need git worktrees if I use gitta?

Yes. Worktrees keep each agent's files apart, so agents don't write over each other. gitta works on top of them. It reads every worktree of the repository and tells an agent when another agent's change affects its work. See Why git worktrees don't prevent agent conflicts.

Does gitta work with Conductor, Claude Squad or Vibe Kanban?

Yes. These tools start agents in git worktrees, and gitta finds every worktree through git worktree list. Keep using the tool you like to start and manage agents. gitta adds the warnings between them and the checks inside your normal git merge. See Other tools and Parallel coding agent tools compared.

Can gitta tell when two agents edit the same file in different worktrees?

Yes. When two agents change the same function or the same lines, both get an also editing note. When one agent changes code that the other agent's new code uses, in any file, the second agent gets a warning with the other agent's new definition. Your tests run on both changes together when you merge. See Warnings and sync.

Does gitta replace code review of AI pull requests?

No. A person still reviews the code. gitta tells the reviewer what changed under an agent's work, which other pull requests touch the same code, and whether the combination passes your tests. It also reports weakened tests and removed security controls, and in CI it stops such a merge by default. See Review agent pull requests.

Does gitta send my code anywhere?

No. gitta runs on your machines and uses no AI model. With Enterprise, the team server runs in your own cloud account or cluster and receives only the files an agent changed. Nothing goes to gitta's company. See Security and data.

Does the EU AI Act require logging of AI-written code?

The AI Act's record-keeping duty in Article 12 is for high-risk AI systems, and most of its duties fall on providers and deployers of AI systems. Whether it reaches your code depends on what you build, so ask your legal advisers. When you want a record of how agents took part in your development, gitta's audit trail gives one. See EU regulations.

Does gitta work with Git on z/OS and EBCDIC files?

Yes, with gitta Enterprise. gitta runs on Linux and macOS, next to Git for z/OS. It reads the code page of each folder from .gitattributes, and it reports changes that only a wrong conversion would make as a weakened check. See Git and EBCDIC.

Which agents does gitta work with?

Claude Code through hooks, Cursor and Codex through MCP tools, any tool that makes git worktrees, and cloud agents that open pull requests. See Agents.
