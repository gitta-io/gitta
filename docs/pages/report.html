Usage report

gitta report shows what gitta did for a repository. It counts how many agents ran, how much work reached main, and how often gitta found a clash or stopped a merge. It reads the audit trail, so it needs no setup.

Run it

$ gitta report period repo agent agents changes clashes stopped broken mains prevented 2026-W43 microblog add-search 1 4 2 1 1 2026-W43 microblog rate-limit 1 3 1 0 0 2026-W43 total 2 7 3 1 1

Each row is one agent in one period. The last row of each period is the total for that period.

ColumnWhat it counts
agentsDifferent agents with any event in the period.
changesWork that reached main through gitta land, a merge that gitta checked, or a commit that reached main with plain git.
clashesWarnings to an agent about work of another agent, such as a function that changed under its new code.
stoppedMerges and landings that gitta refused, for any reason.
broken mains preventedStopped merges where the tests failed on the combined code. Without gitta, that code would have been on main.

Options

OptionUse
--period day|week|month|allThe length of each period. Weeks are ISO weeks. Default week.
--by agent|person|repoOne row per agent, per person or per repository. Default agent.
--since 2026-10-01, --until 2026-10-31Only events in this time. Both dates are included.
--csv, --jsonOutput for a spreadsheet or another tool.
--teamThe whole team from the team server, over every repository and machine. Enterprise
$ gitta report --period month --csv > october.csv $ gitta report --by person --json

For the whole team Enterprise

With a team server, every machine sends its audit events to the server. gitta report --team asks the server for one report over all of them. Use --by person to see each person, or --by repo to see each repository.

$ gitta report --team --by repo --period month period repo agents changes clashes stopped broken mains prevented 2026-10 billing 4 18 2 1 1 2026-10 microblog 6 41 9 3 2 2026-10 total 10 59 11 4 3

The same report is at GET /v1/usage on the server, with the parameters period, by, since, until and format (json, csv or text). Any personal or admin token can read it.

$ curl -s -H "Authorization: Bearer $GITTA_SERVER_TOKEN" \ "https://gitta-1.example.com/v1/usage?period=week&format=csv"

For each event behind the numbers, see Audit trail.
