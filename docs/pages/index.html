gitta documentation

gitta coordinates AI coding agents that work in the same repository at the same time. It tells an agent when another agent changes code that its new work uses. It runs inside your normal git merge, tests the combined code before main moves and stops the merge when your tests fail. Removed tests and weakened checks are reported in the merge output and the audit trail.

gitta runs on top of Git. It uses the normal git command, and your repository format, branches and pull requests stay as they are. It has no AI inside. It reads code with parsers, applies fixed rules and runs your own tests.

Free and Enterprise

The gitta command is free and open source. It covers everything on one machine, including workspaces, warnings, sync, the merge check, the pull request check and the local audit trail.

gitta Enterprise adds a team server. Agents on different laptops, CI runners and cloud agents then warn each other too. Enterprise also adds more languages and platforms, personal tokens, SSO, a team-wide audit trail and deployments for Kubernetes, Google Cloud, AWS and Azure. The server runs in your own account.
